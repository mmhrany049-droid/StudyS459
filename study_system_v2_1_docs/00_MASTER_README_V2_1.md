# مستند مادر — نسخه 2.1 (SS459)

## هدف
نسخه 2.1 تمام قابلیت‌های نسخه 2 را حفظ می‌کند و یک لایه جدید به نام **Behavioral Intelligence Layer** اضافه می‌کند؛ هدف آن شناخت تدریجی کاربر، درک رفتار واقعی، تخمین وضعیت فعلی و تولید/تطبیق برنامه شخصی است.

نسخه 2.1 نباید هسته نسخه 1 را بشکند:
- Range + odd/even/any
- correct / wrong / unanswered
- history append-only
- Goals پایه
- Planner افق جمعه
- Coverage جدا از Accuracy
- Telegram اختیاری

## محورهای نسخه 2.1
1. تمام قابلیت‌های V2
2. پروفایل شخصیت و ترجیحات
3. پرسشنامه اولیه گسترده و تطبیقی
4. پرسش‌های مهم ابتدای هر هفته برای تصمیم‌گیری هفتگی
5. مدل رفتار واقعی بر اساس داده‌های ثبت‌شده
6. تخمین وضعیت فعلی: انرژی، تمرکز، انگیزه، استرس، خستگی و آمادگی
7. تشخیص الگوهای اهمال‌کاری و ظرفیت واقعی انجام کار
8. برنامه‌ریزی تطبیقی بر اساس هدف + رفتار + وضعیت
9. حلقه یادگیری: Plan → Act → Observe → Evaluate → Update
10. confidence برای جلوگیری از نتیجه‌گیری زودهنگام
11. امکان ویرایش دستی کامل برنامه و حفظ اولویت تصمیم کاربر

## اصل طلایی 2.1
سیستم نباید کاربر را مجبور کند طبق برنامه خودکار رفتار کند. سیستم باید پیشنهاد بدهد، توضیح بدهد و از رفتار یاد بگیرد؛ **کاربر همیشه امکان ایجاد، حذف، جابه‌جایی، تغییر تعداد، اولویت، روز، زمان و وضعیت کارها را دارد.**

## اصل داده
Self-report و Observed Behavior جدا ذخیره و سپس با هم ترکیب شوند. هیچ ویژگی شخصیتی نباید صرفاً از یک پاسخ نتیجه‌گیری شود.

## برنامه روزانه
برنامه ترجیحاً بر اساس «تعداد کار / تعداد وعده» باشد و ساعت‌بندی خشک تحمیل نکند، مگر کاربر خودش زمان مشخص تعیین کرده باشد.
