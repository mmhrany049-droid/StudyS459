# ورود تست‌های زده‌شده قبلی (نسخه ۲.۲)

## جریان ساده‌شده (طبق خواست کاربر)
1. فقط **کتاب** را انتخاب می‌کند (نه الزاماً مبحث از اول)
2. سیستم لیست بزرگ سوال‌ها را می‌آورد (گروه‌بندی‌شده بر اساس فصل/مبحث در UI)
3. برای هر سوال یکی از این‌ها:
   - گزینه ۱
   - گزینه ۲
   - گزینه ۳
   - گزینه ۴
   - **نزده / زده‌نشده** (وضعیت جدا)
4. ذخیره → attemptها ثبت می‌شوند + analytics + review_queue برای غلط و نزده

## حالت جایگزین (دقیق‌تر)
فیلتر اختیاری: فصل یا مبحث، برای کوتاه شدن لیست.

## قوانین
- `is_imported = true`
- سکه داده نمی‌شود
- `unanswered` با wrong قاطی نشود
- اگر کاربر فقط کتاب را انتخاب کند، سوال‌ها با برچسب مبحث نمایش داده شوند تا بعداً آمار موضوعی درست بماند
