# فقط تاریخ هجری شمسی

## قانون سخت
- در **کل UI** هیچ تاریخ میلادی نمایش داده نشود.
- پیام‌ها، فیلترها، محور نمودارها، انتخابگر تاریخ: شمسی.
- نام روزها فارسی؛ هفته از شنبه.

## ذخیره داخلی
- ترجیح: ذخیره لحظه‌ای UTC یا aware datetime؛ تبدیل نمایش فقط به جلالی.
- اگر قبلاً فیلد date میلادی در API بوده، response نمایشی باید jalali string جدا داشته باشد و UI فقط همان را نشان دهد.
- هدف محصول: کاربر هیچ جا سال ۲۰۲۶ را برای برنامه‌ریزی نبیند.

## انتخابگر
Date picker شمسی (سال/ماه/روز جلالی).
