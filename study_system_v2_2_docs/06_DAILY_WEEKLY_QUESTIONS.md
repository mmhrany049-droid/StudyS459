# سوالات روزانه و هفتگی

## آغاز روز (۲ تا ۵ سوال کوتاه)
نمونه‌موضوع: انرژی، خواب، زمان آزاد امروز، اولویت ذهنی، استرس امتحان
→ ورودی State Engine همان روز

## پایان روز (۲ تا ۵ سوال)
نمونه‌موضوع: چقدر طبق برنامه پیش رفتی، entیجه، حواس‌پرتی، رضایت
→ Behavior events + تنظیم streak/عادت (بدون تنبیه افراطی)

## پایان هفته (پس از جمع‌بندی کارها)
نمونه‌موضوع: سخت‌ترین مبحث، بهترین عادت، چه چیزی را حذف/اضافه کنی
→ ورودی مصاحبه/برنامه هفته بعد

## هنگام ساخت برنامه هفتگی جدید
چند سوال هدف‌گذاری: ظرفیت واقع‌بینانه، تمرکز روی کدام درس، محدودیت‌های هفته
→ Candidate tasks و وزن‌ها

## قوانین
- اجباری کامل نباشند (قابل Skip با ثبت skipped)
- تاریخ و زمان رویداد شمسی در UI
- ذخیره append-only
