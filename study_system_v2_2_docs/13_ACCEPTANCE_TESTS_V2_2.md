# Acceptance نسخه ۲.۲ اصلاح‌شده

- ویژگی‌های قبلی (تست Range/parity، planner، rewards، ۲.۱) بعد از ۲.۲ همچنان کار می‌کنند
- در هر کتاب مسیر جدا برای بانک تست مبحث وجود دارد و لیست چهارگزینه‌ای جواب ذخیره می‌شود
- ورود گذشته: انتخاب کتاب → لیست → ۱..۴ یا نزده → ثبت
- تیک فصل همه فرزندان را تدریس‌شده می‌کند
- UI تاریخ میلادی نشان نمی‌دهد
- پرسشنامه شخصیت با یک پاسخ، یک بُعد را جهش بزرگ نمی‌دهد
- سوال آغاز/پایان روز و هفتگی قابل ثبت است
- تلگرام optional؛ قطع بودنش اپ را خراب نمی‌کند
- امتحان با فایل و چند نوبت+زمان؛ آزمایشی چندمبحثی؛ آمادگی پیشنهاد از همان مباحث
