# مستند مادر — نسخه ۲.۲ (SS459) — اصلاح‌شده

## اصل مهم
نسخه ۲.۲ باید **همه قابلیت‌های نسخه‌های قبلی (۱ / ۲ / ۲.۱)** را داشته باشد.
این بسته فقط **تغییرات و افزوده‌های ۲.۲** را شرح می‌دهد؛ حذف هسته قبلی ممنوع است.

## شعار ۲.۲
بانک تست per مبحث + تدریس‌شده درختی با تیک + ورود پاسخ/گذشته درست + امتحان + آمادگی + شخصیت قوی‌تر + سوالات روزانه/هفتگی + تاریخ فقط شمسی

## تغییرات نسبت به ۲.۱
1. بانک تست و پاسخ‌نامه داخل هر کتاب/مبحث (توضیح خیلی دقیق برای agent)
2. ورود تست قبلی: کتاب → لیست بزرگ چهارگزینه + نزده (توضیح دقیق)
3. تدریس‌شده با تیک؛ تیک فصل = تیک همه فرزندان
4. تقویت پرسشنامه شخصیت (چندپهلو)
5. سوالات آغاز/پایان روز و پایان هفته / ساخت برنامه هفتگی
6. حذف نمایش تاریخ میلادی؛ فقط هجری شمسی
7. ربات تلگرام افزونه اختیاری (غیرحیاتی)
8. حفظ ویژگی‌های قبلی + پیشنهادهای سند ۱۲
