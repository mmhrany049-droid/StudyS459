## اصل
نسخه ۲.۱ تغییر نمی‌کند.  
همهٔ قابلیت‌های این بسته فقط به نسخه ۲.۲ اضافه می‌شوند و روی ۲.۱ سوار می‌گردند.

## شعار نسخه ۲.۲
**بانک تست متصل به مبحث + تدریس‌شده + امتحان واقعی/آزمایشی + آمادگی امتحان**

## محورها
1. تعریف تست و پاسخ‌نامه چهارگزینه‌ای برای هر مبحث داخل خود برنامه
2. وارد کردن تست‌های قبلی فقط با انتخاب کتاب + لیست بزرگ پاسخ (با گزینه نزده)
3. بخش «تدریس‌شده» و پیشنهاد مباحث/تست‌های نزده
4. امتحانات با PDF/عکس، پاسخ‌نامه، نتایج چندباره و زمان هر نوبت
5. امتحان آزمایشی چنددرسه با نگاشت مبحث‌های هر درس
6. آمادگی امتحان: تاریخ + مباحث → پیشنهاد تست همان مباحث
7. پیشنهادهای اضافی UX/ایمنی/سرعت ورود (سند ۱۲)
