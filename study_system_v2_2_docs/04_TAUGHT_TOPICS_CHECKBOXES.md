# تدریس‌شده — مدل تیک سلسله‌مراتبی

## UI
در درخت هر کتاب، کنار هر node یک **چک‌باکس** «تدریس‌شده».

## رفتار سلسله‌مراتبی (الزامی)
- اگر کاربر تیک **فصل** را بزند:
  - همه فرزندان مستقیم و غیرمستقیم (درس/عنوان/بخش/زیربخش) تدریس‌شده می‌شوند.
- اگر تیک فصل را بردارد:
  - همه فرزندان هم برداشته می‌شوند (یا با تأیید کاربر).
- اگر همه فرزندان یک پدر تیک بخورند → پدر می‌تواند حالت indeterminate یا full شود.
- تیک یک برگ فقط همان مبحث را علامت می‌زند.

## داده
`taught_topics(user_id, node_id, taught_at, source)`  
برای عملیات فصل: transaction که همه descendantها را upsert کند.

## بینش
- لیست مباحث تدریس‌شده با Coverage/Accuracy
- پیشنهاد تست برای تدریس‌شده‌های کم‌تمرین یا بدون attempt
- هشدار: تدریس‌شده بدون سوال در بانک
