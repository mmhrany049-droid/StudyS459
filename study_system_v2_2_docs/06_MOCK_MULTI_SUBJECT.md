# امتحان آزمایشی چنددرسه

## تفاوت با امتحان تک‌درس
یک آزمون آزمایشی می‌تواند همزمان شیمی + حسابان + فیزیک (و بیشتر) داشته باشد.

## قابلیت‌ها
- تعریف بخش‌های آزمون به تفکیک درس (مثلاً ۳۰ شیمی، ۲۵ حسابان، ۲۵ فیزیک)
- برای هر سوال یا هر بازه سوال: انتخاب **مبحث** از درخت همان درس
- پاسخ‌نامه سراسری شماره‌گذاری‌شده
- نتیجه کلی + نتیجه per subject + در صورت امکان per topic

## UI پیشنهادی
1. ساخت «آزمون آزمایشی»
2. افزودن بلاک درس
3. نگاشت بازه شماره سوال → مبحث
4. ورود پاسخ‌نامه
5. ثبت نوبت اجرا + زمان کل یا زمان per بخش (اختیاری)
