# بانک تست داخل برنامه (هر مبحث)

## مسیر UI
کتاب‌ها → انتخاب کتاب → درخت مبحث → «بانک تست این مبحث»

## کارها
1. دیدن لیست سوال‌های موجود (`sequence_no` مرتب)
2. افزودن بازه سریع: از N تا M (سوال‌ها ساخته می‌شوند، جواب بعداً)
3. ورود / ویرایش **پاسخ‌نامه** به شکل لیست بزرگ چهارگزینه‌ای:
   - برای هر شماره: دکمه‌های ۱ | ۲ | ۳ | ۴
   - یا ورودی فشرده مثل: `1:2, 2:3, 3:1, ...`
4. ذخیره `answer_key` برای هر `sequence_no`
5. اختیاری: سطح سختی ۱/۲/۳ (حسابان)

## قوانین
- `sequence_no` در هر Test Set یکتا
- بدون جواب هم می‌توان سوال داشت (برای ورود تدریجی)
- حذف سوال فقط اگر attempt تاریخی ندارد؛ وگرنه آرشیو نرم

## نتیجه برای موتور تست
انتخاب Range + parity فقط از سوال‌های همین مبحث / همین test_set.
