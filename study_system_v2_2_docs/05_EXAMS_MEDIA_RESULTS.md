# امتحانات — فایل، پاسخ‌نامه، نتایج چندنوبته

## ذخیره فایل
- PDF و/یا عکس صورت امتحان
- ذخیره در storage محلی/سرور با مسیر و metadata
- امکان چند فایل برای یک امتحان

## فیلدهای امتحان
- title, subject(s), exam_date, exam_type (مدرسه‌ای / نهایی / دیگر)
- total_questions
- پاسخ‌نامه رسمی (لیست چهارگزینه‌ای یا کلید به ازای شماره)

## هر نوبت آزمون (attempt روی همان برگه/آزمون)
- تاریخ نوبت
- مدت زمان صرف‌شده (دقیقه) — اجباری یا قویاً توصیه‌شده
- پاسخ‌های کاربر (۱..۴ یا نزده)
- نتیجه: correct/wrong/unanswered counts + درصد
- یادداشت

## تحلیل
- مقایسه نوبت‌ها روی یک امتحان (پیشرفت درصد و زمان)
- اتصال اختیاری سوال به مبحث اگر نگاشت شده باشد
