# پیشرفت و تحلیل — نسخه ۱

## مفاهیم مستقل (نسخه ۱)

### Volume
حجم فعالیت (تعداد attemptها).

### Coverage
چه مقدار از pool هدف حداقل یک بار attempt شده.

### Accuracy
در تلاش‌های پاسخ‌داده‌شده، چند درصد درست بوده.

در نسخه ۱ Mastery پیشرفته پیاده نمی‌شود (به نسخه ۲ منتقل شده).

Coverage ≠ Accuracy ≠ Volume.

## نمونه سیگنال
Coverage پایین + accuracy بالا → دامنه کم، عملکرد خوب روی بخش دیده‌شده.  
Coverage بالا + accuracy پایین → دامنه خوب، کیفیت نیازمند تقویت.  
Unanswered بالا → سیگنال احتمالی مشکل زمان/اعتماد/آمادگی.
