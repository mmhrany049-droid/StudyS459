# سیستم جایزه — نسخه ۱

## هدف
ایجاد انگیزه پایدار و بازخورد فوری بدون پیچیده‌کردن منطق اصلی.

## امتیاز (Points)
- هر تست درست: +۲
- هر تست غلط یا نزده که بعداً مرور و درست شود: +۱
- تکمیل یک Task مطالعه: +۵
- تکمیل هدف روزانه: +۱۵
- تکمیل هدف هفتگی: +۵۰
- هر روز streak: +۵ اضافی

## Streak
- تعداد روزهای متوالی که حداقل یک Task مطالعه با وضعیت completed ثبت شده باشد.
- اگر یک روز کامل بدون فعالیت بگذرد، streak صفر می‌شود.
- longest_streak ذخیره می‌شود.

## نشان‌ها (Badges) — نسخه ۱
- first_20_tests: اولین ۲۰ تست
- chapter_coverage_80: اولین فصل با Coverage ≥ ۸۰٪
- streak_7: ۷ روز streak
- streak_30: ۳۰ روز streak
- accuracy_75: دقت ≥ ۷۵٪ در یک مبحث با حداقل ۲۰ تست
- weekly_topic_goal: تکمیل یک هدف موضوعی هفتگی

## رویدادها
هر کسب امتیاز یا نشان در جدول reward_events ثبت می‌شود.

## نمایش
- داشبورد: امتیاز کل + streak فعلی + آخرین نشان‌ها
- بعد از Finish تست یا Complete Task: پیام کوتاه + امتیاز کسب‌شده
- صفحه جداگانه تاریخچه امتیاز و نشان‌ها

## قانون
سیستم جایزه روی منطق برنامه‌ریزی و انتخاب تست تأثیر اجباری ندارد (فقط انگیزشی است).  
در نسخه‌های بعدی می‌توان از آن برای اولویت‌بندی استفاده کرد.
