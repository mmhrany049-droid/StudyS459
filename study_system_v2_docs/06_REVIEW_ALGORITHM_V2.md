# الگوریتم مرور نسخه ۲

## ورودی
سوالات wrong / unanswered در review_queue

## قوانین
- ترتیب نمایش: **تصادفی**
- انتخاب از خوشه **موضوعی نزدیک**
- نزدیک = اشتراک node در topic map یا والد مشترک تا عمق ۲

## اعداد قطعی
- حداکثر سوال در جلسه مرور: ۲۵
- حداقل مطلوب خوشه: ۸
- Critical اگر wrong_count ≥ ۲ → بازگشت هدف حداکثر ۲ روز
- wrong/unanswered عادی → حداکثر ۳ روز
- پنج‌شنبه/جمعه وزن مرور بالاتر

## خروج از صف
- پاسخ درست در مرور → resolve
- پاسخ غلط مجدد → افزایش priority و زودتر شدن scheduled_for
