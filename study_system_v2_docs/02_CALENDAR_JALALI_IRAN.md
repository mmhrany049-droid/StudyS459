# تقویم و هفته ایرانی

## هفته
شروع هفته: **شنبه**  
پایان هفته: **جمعه**

ترتیب نمایش:
1. شنبه
2. یکشنبه
3. دوشنبه
4. سه‌شنبه
5. چهارشنبه
6. پنج‌شنبه
7. جمعه

## روزهای مدرسه (پیش‌فرض)
- شنبه تا چهارشنبه: روز مدرسه
- پنج‌شنبه و جمعه: آزاد / Catch-up

## فصل‌ها (پیش‌فرض ایران)
- پاییز، زمستان، بهار: حالت مدرسه فعال
- تابستان: حالت تعطیلی (ظرفیت کامل‌تر)

پیاده‌سازی پیشنهادی:
- `season_mode`: `school_term` | `summer`
- قابل override دستی توسط کاربر
- `school_day_overrides` برای یک تاریخ مشخص («امروز مدرسه نمی‌روم»)

## تاریخ هجری شمسی
- تمام تاریخ‌های **نمایشی** UI باید شمسی باشند (مثال: ۱۴۰۴/۰۶/۲۴).
- ذخیره‌سازی داخلی می‌تواند میلادی/UTC بماند؛ تبدیل در لایه presentation.
- هفته و «جمعه برنامه‌ریزی» بر اساس تقویم شمسی کاربر در timezone `Asia/Tehran` محاسبه شود.

## کتابخانه پیشنهادی
- Backend: یک util تبدیل جلالی (بدون وابستگی سنگین اگر ممکن است)
- Frontend: نمایش جلالی یکدست در تمام صفحات تاریخ

## برچسب‌های UI
- «این هفته (شنبه … جمعه)»
- «برنامه‌ریزی جمعه برای هفته بعد»
- روزها همیشه با نام فارسی
