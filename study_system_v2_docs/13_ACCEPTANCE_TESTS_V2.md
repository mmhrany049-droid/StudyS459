# Acceptance Tests — نسخه ۲

- تاریخ‌ها در UI شمسی و هفته از شنبه است
- سه کلاس پیش‌فرض حسابان/شیمی/فیزیک قابل seed هستند
- Import تست قبلی attempt می‌سازد و سکه نمی‌دهد
- پایان Untimed درخواست مدت می‌کند و میانگین قابل محاسبه است
- مرور ترتیب رندوم و خوشه موضوعی دارد
- wake-up قبل ۷ سکه می‌دهد
- قبل از ۳۰ روز advice عادت نشان داده نمی‌شود؛ بعد از آن نشان داده می‌شود
- روز کلاس، تست همان درس اولویت بالاتر دارد
