# ظاهر نسخه ۲

## فونت فارسی
- یک فونت فارسی خوانا برای کل UI (مثلاً Vazirmatn یا معادل سیستم‌مجاز)
- اعداد فارسی یا لاتین یکدست در کل محصول (تصمیم: نمایش تاریخ شمسی با ارقام فارسی مجاز)

## حس غیرخشک
- فاصله‌گذاری بهتر کارت‌ها
- انیمیشن سبک: تغییر صفحه، افزودن Task، Finish تست، کسب سکه
- حالت خالی (empty state) با متن راهنما، نه صفحه سفید

## تاریخ
همه تاریخ‌ها شمسی + نام روز فارسی

## صفحات اولویت پولیش
Dashboard، Today، Test Session، Progress، Schedule
