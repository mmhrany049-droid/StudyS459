# کلاس‌های تقویتی پیش‌فرض

هنگام راه‌اندازی اولیه کاربر (یا دکمه «افزودن کلاس‌های پیش‌فرض»)، این سه کلاس تقویتی ساخته شوند.

## پیش‌فرض‌ها

| عنوان | درس (subject) | نوع | تکرار پیش‌فرض | یادداشت |
|-------|----------------|-----|----------------|---------|
| کلاس تقویتی حسابان | حسابان / ریاضی | external_class | هفتگی — روز خالی برای انتخاب کاربر | |
| کلاس تقویتی شیمی | شیمی | external_class | هفتگی — روز خالی برای انتخاب کاربر | |
| کلاس تقویتی فیزیک | فیزیک | external_class | هفتگی — روز خالی برای انتخاب کاربر | |

## فیلدهای هر کلاس
- title
- subject_id (یا نام subject)
- day_of_week (nullable تا کاربر پر کند)
- start_time / end_time (nullable)
- recurring = true
- source = "default_seed_v2"

## اثر روی برنامه‌ریزی
در روزهایی که یکی از این کلاس‌ها فعال است:
- کاندیدهای تست همان درس **+۱۵** امتیاز اولویت می‌گیرند (مطابق الگوریتم V2).
- ظرفیت آن روز با مدت کلاس کاهش می‌یابد.

## UI
- صفحه Schedule: سه کارت پیش‌فرض با امکان ویرایش روز/ساعت یا حذف
- دکمه «بازنشانی کلاس‌های پیش‌فرض» فقط اگر حذف شده باشند
