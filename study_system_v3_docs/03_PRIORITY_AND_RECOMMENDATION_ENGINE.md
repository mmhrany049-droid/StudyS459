# Priority and Recommendation Engine

Priority answers WHAT matters; Recommendation answers WHAT to do; Planner answers WHEN.

Inputs: exams, goals, taught eligibility, learning need, coverage, accuracy, review, retention risk, recency, prerequisites, difficulty, capacity, behavior, time-of-day evidence and user feedback.

Exam urgency raises relevant topics but does not erase long-term goals, review or capacity.

Before weekly planning, present explainable priority suggestions. User can accept, increase, decrease, reject or add priorities. Store this as user-decision data.

Choose intervention type before selecting questions. Range/Parity is only a minor question-selection signal.

Every recommendation stores reasons, evidence, confidence and model version.
