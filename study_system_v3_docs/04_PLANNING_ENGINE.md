# Planning Engine

Automatically generate a weekly plan, then allow manual editing.

Pipeline: context → exams → goals → taught topics → learning state → review → priority → adaptive questions → capacity → interventions → duration → allocation → overload check → explanation → plan → user edits → finalization.

Questions are uncertainty/information-value driven, not a fixed questionnaire.

Activities reduce availability and are never failed study tasks. Capacity uses historical completion and actual duration.

Recovery redistributes missed work rather than dumping it on tomorrow. Exceptional days are constraints/context.

Store auto plan, user-edited final plan and actual execution for personalization.
