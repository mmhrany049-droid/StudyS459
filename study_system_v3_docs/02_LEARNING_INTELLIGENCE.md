# Learning Intelligence

Learning state is multidimensional: accuracy, coverage, retention estimate, confidence, recency, difficulty-adjusted performance, repeated errors, time performance, exam readiness and prerequisite health.

Weakness must not be calculated from wrong-count alone. Distinguish low/high coverage from low/high accuracy and uncertainty.

When evidence is uncertain, a short diagnostic can be preferable to a large remediation block. Inspect prerequisites when a higher-level topic appears weak.

Error categories may include conceptual, procedural, calculation, careless, misread, time pressure, unknown, guess and memory. Infer only when evidence supports it; ask the user only when useful.

Review can use retrieval and spacing principles, with configurable parameters and evidence validation. Derived models must be versioned and recalculable.
