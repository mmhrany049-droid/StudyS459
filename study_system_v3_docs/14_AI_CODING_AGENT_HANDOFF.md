# AI Coding Agent Handoff

Treat the Master Production Specification as the V3 source of truth.

Before significant code: inspect repository, stack, existing docs/data/assets, implementation status and migration needs. Do not immediately rewrite everything.

Always ask: which entity owns this data? Which layer owns this logic? What raw data does it depend on? What derived data does it produce? How is it recalculated? How is it tested?

Never assume: taught=learned, one error=weakness, one success=mastery, free time=capacity, missed task=failure, generic morning/night preference, accepted recommendation=quality, or old V2 numeric rules=V3 truth.

If information is missing, do not invent it. Use explicit unknowns, conservative defaults, configurable parameters and documented assumptions.

Core loops:
Question → Response → Result → Learning State → Priority → Recommendation → Task → Execution → New Evidence.
Exam → Relevance → Priority → Plan → Preparation → Result → Learning State.
Goal → Milestone → Objective → Task → Execution → Progress → Replan.
Availability → Capacity → Plan → Actual → Capacity update.
Recommendation → User Feedback → Behavior → Evaluation → Personalization.

The objective is a reliable personal adaptive learning system, not merely a task manager and not merely an AI chatbot.
