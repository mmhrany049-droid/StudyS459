# Testing and Acceptance

Unit tests: Jalali conversion, topic cascade, accuracy, coverage, priority, duration, capacity, dependencies.

Integration: question→response→result→learning state; exam→priority→plan; goal→milestone→task→execution→progress.

E2E scenarios must cover: taught vs learned; ANSWERED/UNANSWERED/NOT_ENTERED; answer-key correction; multi-topic questions; upcoming exam; mock exam planned-vs-actual topics; three-month goal; activity constraints; capacity/anti-overplanning; recovery; first-month duration; personalized duration; adaptive interview; priority feedback; explainability; recalculation; dependency cycles; migration.

No silent corruption, hidden magic numbers, business logic trapped in UI or automatic overwriting of manual edits.
