# Implementation Roadmap

Phase 0: repository/stack/data audit.
Phase 1: foundation, DB, dates, migration, subjects/books/topics.
Phase 2: questions, answer keys, response sheets, attempts and historical import.
Phase 3: learning state, coverage, accuracy, review, prerequisites.
Phase 4: school/mock exams and future exam intelligence.
Phase 5: long-term goals/milestones/objectives.
Phase 6: activities/capacity/exceptional days/recovery.
Phase 7: priority/intervention/question selection/duration/planner/adaptive interview.
Phase 8: behavior, state, personalization and experiments.
Phase 9: analytics and explainability.
Phase 10: notifications/quiet suggestions/optional Telegram/export.

At every phase: tests, raw/derived separation, versioned algorithms, documented assumptions and no magic numbers.
