# Time Estimation Engine

First month: do not ask for predicted duration. After completion ask actual duration. Use a broad 60–120 minute test-session range where needed.

Later, estimate personalized ranges with confidence using subject, topic, task type, question count, difficulty, timed state, time of day, day and user state when evidence exists.

Store prediction and actual duration. Detect systematic patterns rather than only global averages. Evaluate interval coverage and prediction error. Use broad low-confidence fallbacks when evidence is sparse.
