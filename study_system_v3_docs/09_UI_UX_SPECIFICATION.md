# UI/UX Specification

Primary language: Persian; support RTL and Jalali presentation.

Dashboard answers: What matters now? What next? Why? How much realistic time? Which exams? Which goal?

Weekly planning: priority suggestions → adaptive questions → planning animation → editable auto-plan → finalize.

Daily task UI: time, task, topic, duration range, reason, status. After completion ask actual duration; optionally ask difficulty/blocker.

Topic page: taught state, learning state, coverage, accuracy, confidence, review, prerequisites, exam/goal relevance and recommendation.

Response sheet: fast option entry; distinguish ANSWERED, UNANSWERED and NOT_ENTERED.

Calendar visibly distinguishes Activities, Study Tasks, Exams and deadlines.

UI should expose complexity only when useful for trust. Manual control is always available.
