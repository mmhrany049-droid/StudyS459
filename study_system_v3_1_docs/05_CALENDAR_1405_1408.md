# موتور تقویم جلالی ۱۴۰۵–۱۴۰۸

## نیاز
سیستم کاملاً Jalali-aware برای سال‌های ۱۴۰۵، ۱۴۰۶، ۱۴۰۷، ۱۴۰۸.

## قابلیت‌ها
- تشخیص کبیسه
- تبدیل داخلی در صورت نیاز (ذخیره می‌تواند UTC باشد؛ نمایش فقط شمسی)
- روز هفته (هفته از شنبه)
- تعطیلات و مناسبت‌ها (قابل گسترش؛ حداقل ساختار داده)
- اتصال event: Exam، StudyTask، Activity

## ساختار مفهومی
```
CalendarDay
├── jalali y/m/d
├── weekday
├── is_holiday
├── events[]
```
