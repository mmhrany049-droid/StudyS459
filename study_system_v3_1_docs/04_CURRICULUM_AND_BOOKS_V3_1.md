# Curriculum و کتاب‌ها V3.1

## پایه کاربر
`current_grade = 11` (قابل تنظیم بعداً)

## درخت موجود (رشته ریاضی)
- دهم: ریاضی، فیزیک، شیمی
- یازدهم: حسابان، هندسه، آمار، فیزیک، شیمی
- دوازدهم: حسابان، هندسه، گسسته، فیزیک، شیمی

محتوای seed فعلی کاربر روی یازدهم (حسابان۱ الگو، شیمی۲ مبتکران، فیزیک۲ خیلی سبز) حفظ و در صورت نیاز غنی شود.
Migration داده قدیمی حذف نشود.

## قانون زمان‌بندی
```
Topic
├── has book_test / question bank?
│     ├── Yes → وارد تخمین زمان، پیشنهاد تست، planner
│     └── No  → فقط نمایش در Curriculum (موجودیت آموزشی)
```

همه مباحث می‌توانند دیده شوند؛ همه plannable نیستند.

## ساختار کتاب‌های تست یازدهم (یادآوری)
- شیمی: فصل → عنوان → زیرعنوان اختیاری؛ چکاپ سگمنت؛ جامع؛ کنکور آخر کتاب
- حسابان: فصل → درس → بخش + Level 1/2/3؛ کنکور آخر درس
- فیزیک: فصل → بخش → زیربخش
