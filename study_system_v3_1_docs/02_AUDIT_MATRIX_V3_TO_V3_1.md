## گزارش Audit (کد واقعی)

### شکست‌های واقعی که باید جبران شوند
1. **پارسر شیمی صفر گره می‌دهد.** فهرست جدید (`فصل ۱ ـ ...`، `1. موضوع`، `زیرعنوان ۲-۱:`، `• آزمون چکاپ`) با
   regexهای قدیمی (`فصل اول:` و بولت تودرتو) خوانده نمی‌شود؛ نتیجهٔ واقعی:
   `chemistry2-mobtakeran → {chapters: 0, leaves: 0}`. این یعنی محتوای شیمی در V3 گم شده است.
   → فاز ۱: پارسر جدید additive (هم فرمت قدیم، هم جدید) + نشانه‌های چکاپ/جامع.
2. **مهاجرت schema وجود ندارد.** `init_db` فقط `create_all` است؛ روی دیتابیس داده‌دار V3 ستون جدید اضافه نمی‌شود.
   → فاز ۱: `sync_schema` additive (ALTER TABLE ADD COLUMN) بدون حذف داده.
3. **آزمون چنددرسه/پاسخ‌نامهٔ آزمون/نوبت‌ها ناقص است** (نوع، `subjects[]`، `answer_key[]`, `attempts[]`).
   → فاز ۲.
4. **Checkup range و Curriculum دهم/دوازدهم وجود ندارد.** → فاز ۳ و ۴.
5. **پرسش روزانه به capacity وصل نیست** (acceptance ۱۰). → فاز ۷.

### چیزهایی که سالم‌اند و نباید بشکنند
- بانک تست/پاسخ‌نامه per مبحث، ورود گذشته با «نزده»، cascade تدریس، پوشش چندبُعدی ضعف،
  فایل امتحان، تقویم جلالی دقیق (مبدأ jalaali-js)، reward/idempotency، explainability.
